# Заставка

Заставка заменена на двухчастную анимацию: зацикленный фрагмент
и финальный кадр с приветствием.

## Состав

| Файл | Что |
|---|---|
| `assets/bootanimation/boot_1_loop.svg` | первая часть, зацикливается |
| `assets/bootanimation/boot_2_hello.svg` | вторая часть, играет один раз |
| `bootanimation.zip` | готовый архив (в релизе, не в git — 276 МБ) |

## Формат

`bootanimation.zip`, stored PNG (без сжатия):

```
desc.txt:
720 1600 24
c 0 0 part1
c 1 0 part2
```

- `c` — не прерывать анимацию при завершении загрузки;
- `0 0` — без паузы между циклами;
- `1 0` — вторая часть один раз;
- 24 кадра/с, 96 кадров на часть (4 секунды).

## Установка

Модуль `bootanim_netrunner` кладёт архив поверх
`/system/product/media/bootanimation.zip`:

```
/data/adb/modules/bootanim_netrunner/system/product/media/bootanimation.zip
```

Проверено: полное разрешение 720×1600 работает. Оценка памяти под текстуры
≈ 844 МиБ, из них ≈ 422 МиБ на зацикленную часть — для 3 ГБ RAM это
ощутимо, но загрузка проходит.

## Пересборка

SVG → PNG 720×1600, 24 fps, 96 кадров на часть, затем упаковать
`zip -0` (только store). Рендер делался офлайн через Chromium в headless
режиме; готовый `bootanimation.zip` лежит в релизе.

## Откат

```bash
adb shell su -c 'rm -rf /data/adb/modules/bootanim_netrunner'
adb reboot
```

## Предупреждение

Не запускать `bootanimation` вручную на живом экране: анимация перекрывает
интерфейс и телефоном нельзя пользоваться, пока она не закончится.
Только офлайн-просмотр кадров.
