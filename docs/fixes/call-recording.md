# Запись звонков

## Симптом

В LineageOS 22.1 нет штатной записи звонков, а сторонние приложения
не получают доступ к аудиопотоку вызова.

## Решение — BCR (`com.chiller3.bcr`)

Не пишем свой рекордер: `Basic Call Recorder` уже умеет системную запись
через привилегированный доступ и Magisk.

1. Установить модуль из релиза проекта:
   <https://github.com/chenxiaolong/BCR/releases>
2. Разрешить чтение журнала вызовов:
   ```bash
   adb shell su -c 'pm grant com.chiller3.bcr android.permission.READ_CALL_LOG'
   ```
3. В приложении BCR выбрать папку записей (например `/sdcard/Recordings/BCR`).
4. Совершить тестовый звонок и проверить, что появился файл.

Записи — `.m4a`, обе стороны, стерео: одна дорожка вызывающий,
вторая — вы.

## Проверка

```bash
adb shell su -c 'ls -la /sdcard/Recordings/BCR'
adb shell 'logcat -d | grep -i bcr | tail -30'
```

## Почему не свой модуль

Системная запись требует `CAPTURE_AUDIO_OUTPUT` и привилегий системного
приложения. BCR уже решает это корректно и обновляется. Свой рекордер
пришлось бы поддерживать вечно, а выигрыша нет.

## Откат

```bash
adb shell su -c 'rm -rf /data/adb/modules/com.chiller3.bcr'
adb reboot
```

## Ограничения

- Запись в LTE зависит от IMS: без [`km4-stock-ims`](ims.md) звонка
  в LTE может не быть вовсе.
- Законодательство о записи разговоров зависит от страны; согласие
  второй стороны — на пользователе.
